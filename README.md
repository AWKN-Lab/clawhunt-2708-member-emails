# clawhunt-2708-member-emails

ClawHunt #2708 样品仓（任务编码 S4-BRAND-018）：会员空间平台 · 上线公告与
账号开通邮件——会员公告、激活邀请、员工开通与激活提醒。

基于 HTML 邮件基础框架（单栏 600 px、表格布局、内联 CSS）制作上线阶段的
4 封邮件：①会员上线公告；②会员账号激活邀请；③员工工作台开通通知；
④激活提醒。每封都有 HTML 与纯文本两个版本，共用同一套页眉页脚组件
（`src/emails.py` 的 `render_header` / `render_footer`）。
只用虚构测试数据：收件人张三（虚构）、示例科技有限公司；邮件中不出现
真实电话或邮箱地址，地址类内容一律用 `{{变量}}` 占位。

## 一键复跑

```bash
bash setup.sh
```

依次跑：1/3 pytest、2/3 变异自证（`scripts/mutation_check.py`）、
3/3 MANIFEST 核验（`sha256sum -c MANIFEST`）。全部通过末尾打印
`SELFTEST: PASS`。需要 Python 3.11+ 与 pytest（本机已有时直接用，
没有时自动建 `.venv` 并按 `requirements.txt` 安装）。

## 各封要点

- **会员上线公告**：说明平台正式上线、对会员最有用的 3 个功能
  （资源对接、知识库与 SOP 工作台、商机流转）、进入会员端的方式
  （二维码图片位与三步操作），主按钮「查看会员权益」。
- **会员账号激活邀请**：激活链接变量 `{{activation_url}}`；
  链接自发送起 72 小时内有效；过期后点击激活页上的
  “重新发送激活链接”重新获取，或联系会员服务负责人协助重新开通。
- **员工工作台开通通知**：登录账号 `{{staff_login_account}}`、
  首次登录三步、培训资料入口 `{{training_url}}`；
  邮件中不出现密码明文，只给设置密码链接变量 `{{set_password_url}}`。
- **激活提醒**：发给 72 小时内未激活的会员，语气温和、不施压
  （“不着急，慢慢来”“什么时候方便都可以办”）。

## 浅色与深色模式截图

截图办法：用浏览器打开渲染出的 HTML（`render_html` 输出），分别在
浅色与深色模式下截取。HTML 只用内联 CSS 与表格布局，深色模式下由
邮件客户端按自身规则反色；正文颜色均为深色文字配白色底，
不依赖背景图，两种模式下均可读。截图文件不在本样品仓内，
随正式交付物一并提交。

## 对接点

- 身份与账号开通依赖 S2-IAM（身份、角色与数据范围），本样品先用
  `{{staff_login_account}}` / `{{set_password_url}}` 等变量占位，
  未接真实接口；生产接线时由发件服务在发送时填入真实变量值。
- 邮件发送服务、退订处理与发送记录不在本单范围，变量替换与发送
  时机由调用方按上表触发条件执行。
